# PATT Logo：给 Claude 的 SVG 设计提示词

请为开源项目 **PATT-PDF** 设计一份原创、可编辑的 **SVG 矢量 Logo**。PATT 是 Position-Aware Translation Toolkit for PDF 的缩写：核心体验是把英文 PDF 翻译成中文，并尽量将译文放在原文对应的位置，同时保留页面上的数字、图形与版面。

## 设计方向

- 用清晰、克制的**像素艺术 / 像素字体**风格，呈现「文档原位翻译」，而不是泛泛的聊天或 AI 图标。
- Logo 的主体必须能辨认出大写 **PATT**。一条清晰的对角线穿过主体，把画面分成两个区域；对角线是翻译前后的视觉分界，而非把字母切碎到无法辨认。
- 对角线一侧以英文 **“Trans”** 为示例，另一侧以中文 **“译”** 为示例。重点是让两侧文字有**同一位置、对应替换**的感觉：例如分别放在分界线两侧对应的文档行中，保持相同的基线、行框和版面坐标。英文与中文无需逐字等宽，但应能看出它们是同一处内容的不同语言版本。
- 结合简洁的 PDF 页面轮廓或像素网格，暗示页面、排版和精确定位。不要让 PDF 图标喧宾夺主。可通过对齐的细小方块或共同的行框体现位置一致。
- 尝试将 “Trans” / “译” 与 PATT 字标组成一个整体，避免仅把两种文字随意放在画面两边。若空间不足，优先保证 PATT 和分界清晰，示例文字作为辅助；提供一个更易读的横向版本。
- 风格现代、有辨识度、适合开发者工具和 GitHub 项目首页；控制细节，避免渐变、复杂阴影、3D、吉祥物和无意义装饰。配色由你选择，建议 2–3 种高对比色，并考虑浅色和深色背景。

## 输出与约束

1. 先用简短文字解释设计构思，特别说明如何表达「同一位置的翻译」以及对角线与 PATT 的关系。
2. 输出完整、可直接保存的 SVG 源码，带 `viewBox`，透明背景；优先使用基于像素网格的矩形或路径，保持锐利边缘。
3. 将 PATT、“Trans”和“译”转换成 SVG 路径或自绘像素形状，不依赖用户本地安装字体、外链资源、JavaScript 或嵌入的位图。确保字符形态正确、拼写准确。
4. 给出适合 README 的横向主版本，以及适合头像 / favicon 的简化方形图标版本；小尺寸版本允许省略辅助文字，但保留对角线和核心识别元素。
5. 确保在浅色和深色背景上均可辨认；如有必要分别提供两套配色。给出推荐显示尺寸，并检查 32px、64px 和首页较大尺寸下的可读性。
6. 不使用第三方商标、受限字体或现成图标。不要虚构项目功能，也不要在 Logo 中写入尚不存在的 GUI 或其他产品承诺。

请先提出 2–3 个简短构图方案，选择最能体现上述概念的方案并给出 SVG。如果 “Trans” 与 “译” 在小尺寸下太拥挤，可以保留它们在横向版本中，把方形版本简化；不要牺牲字标可读性。
