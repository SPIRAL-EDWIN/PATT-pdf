# Provenance: how PATT-PDF was extracted from a private prototype

PATT-PDF started as a private prototype written to translate a set of slide decks
(English → Simplified Chinese) in place. The prototype code was reviewed and split into
this package; the material it was used on was **not** carried over.

## What was migrated and what was not

| Category | Decision |
|---|---|
| Prototype layout module (page analysis, keep protection, erase, typeset, fonts) | Migrated after review, split into the modules below, hard-coded paths removed |
| Prototype jobs module (translation memory, DeepL client, budget, QA checks) | Partly migrated; the corpus configuration and file skip lists were dropped |
| Time-slice wrappers, sample scripts bound to real files | Not migrated (replaced by the CLI with per-page resume, synthetic fixtures and `patt-pdf compare`) |
| Source documents, their translations, translation memories, run state, ledgers, rendered samples | **Not migrated** (third-party / private content) |
| API keys | Never read, copied or printed. PATT-PDF reads the key from `DEEPL_AUTH_KEY` or a user-chosen key file |
| Fonts (Noto CJK SC, SIL OFL 1.1) | Not committed; `patt-pdf fonts` copies them from the user's system |
| A domain glossary from the prototype | Shipped in v0.1 and v0.2, **removed in v0.3** (too close to the original material); `--glossary` takes the user's own TSV |

All migrated code was written for the prototype; no third-party source code was copied into
it. It *calls* PyMuPDF (AGPL-3.0 / commercial), OpenCV, NumPy, fontTools, Pillow and the
Tesseract CLI. BabelDOC / pdf2zh-next were installed only for a comparison experiment;
none of their code is included. Details: `THIRD_PARTY_NOTICES.md`.

The test corpus is generated by `tests/fixtures/make_fixtures.py` from scratch. Its themes,
names, figures, dates and URLs are invented (rewritten in v0.3 to avoid any resemblance to
the original material).

## Module origin

| Module | Origin in the prototype | Main changes at migration (v0.1) |
|---|---|---|
| `model.py` | `Unit`, `PagePlan` | none |
| `keep.py` | keep/rating/URL rules | none |
| `grouping.py` | paragraph grouping | unused variable removed |
| `extract_text.py` | text-layer extraction | imports only |
| `ocr.py` | Tesseract wrapper, OCR planning | imports only |
| `typeset.py` | wrapping, fitting | context-local font set |
| `render.py` | erase, draw, keep restoration | context-local font set |
| `fonts.py` | font subsetting | runtime discovery, `patt-pdf fonts`, per-document font set |
| `classify.py` | page classification | thresholds fixed after the synthetic baseline (`docs/BASELINE.md`) |
| `analyze.py` | document planning | image inventory (image text reported, not translated) |
| `qa.py` | number, residual-English and keep checks | fresh document handles for keep checks; explicit idiom list; URL check |
| `tm.py` | translation memory | overrides passed explicitly |
| `backends.py` | rate limiter, DeepL client | key handling, injectable HTTP opener, `manual`/`pseudo` backends |
| `jobs.py`, `report.py`, `cli.py` | job functions, argparse | no hard-coded corpus; per-file error boundary; atomic writes; Markdown report |

Changes after v0.1 are recorded in `docs/STATUS.md`. `decor.py` (underlines and links) is new in v0.3.

**Equivalence check at migration:** after the split, planning produced byte-identical plans to
the prototype on all readable synthetic fixtures, before the deliberate classifier change.

**Claims about the prototype that were checked against its code:** keep rules and character
splitting exist; restoration of displaced kept text exists. DeepL XML tag number locking and
table detection were *not* implemented (they remain future work).
